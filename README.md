# Baham Bebinim

یه پروژه برای وقتی که می‌خوای با یکی دیگه از راه دور فیلم ببینی و پخش ویدیو برای همه همزمان بمونه.

اتاق می‌سازی، لینک ویدیو رو می‌ذاری و بقیه با کد اتاق وارد می‌شن. کنار ویدیو هم چت، ریپلای، تگ، ری‌اکشن، عکس و ویس داریم.

## امکانات

- پخش همزمان Play / Pause / Seek
- اتاق با Host، Admin و Role
- چت زنده با Reply و Mention
- ارسال عکس واقعی تا 5MB، کپشن، ویس و گالری رسانه‌های چت
- Seen پیام‌ها
- ری‌اکشن روی ویدیو
- Preview تایم‌لاین
- تشخیص و انتخاب کیفیت واقعی منبع (مثل 240p / 480p / 720p / 1080p) و پیشنهاد ویدیو
- ذخیره ادامه ویدیو برای Host/Admin
- رابط موبایل Portrait و Landscape
- Fullscreen و کنترل‌های مخصوص پلیر
- حذف پیام توسط Host/Admin و نمایش لینک‌های قابل کلیک در چت

## اجرا

```bash
npm install
npm run dev
```

برای Production:

```bash
npm install
npm run build
npm start
```

سرور به‌صورت پیش‌فرض فقط روی `127.0.0.1` Bind می‌شود. برای Production بهتره Node پشت Nginx/Reverse Proxy اجرا بشه و پورت Node مستقیم روی اینترنت باز نباشه.

## تنظیمات

فایل `.env.example` تنظیمات قابل تغییر رو نشون می‌ده. فایل واقعی `.env` داخل Git قرار نمی‌گیره.

برای VPS کوچک، محدودیت اتصال، تعداد اعضای اتاق، تعداد Roomهای فعال و حجم فایل‌های موقت قابل تنظیمه. این محدودیت‌ها برای اینه که Public شدن پروژه باعث مصرف بی‌نهایت RAM/Disk نشه.

## ذخیره ویدیوها

Saveهای کاربر TTL ندارن و خودکار بعد از چند روز پاک نمی‌شن. از نسخه 3.18 به بعد هر Browser Profile فایل جداگانه خودش رو داره؛ یعنی با زیاد شدن کاربرها هر Save باعث بازنویسی یک فایل بزرگ مشترک نمی‌شه.

به‌صورت پیش‌فرض تا 200 Save برای هر Browser Profile نگه داشته می‌شه. این عدد از Environment قابل تغییر است. داده‌های نسخه 3.17 که در فایل قدیمی ذخیره شده بودن، در اولین اجرا به ساختار جدید Import می‌شن و فایل قدیمی هم به‌عنوان Backup دست‌نخورده می‌مونه.

فعلاً Login/Account سروری داخل پروژه وجود نداره؛ شناسه کاربر به Browser Profile وصل است. پس Saveها بین Roomها می‌مونن، ولی بین دو دستگاه مختلف Sync نمی‌شن.

## v3.21.0

- سقف تصویر چت به 5MiB افزایش یافت و نوع واقعی فایل با Magic Bytes در Client و Server بررسی می‌شود؛ SVG و فایل‌های جعلی به‌عنوان تصویر پذیرفته نمی‌شوند. در اتاق خصوصی، Client قبل از رمزنگاری همین بررسی را انجام می‌دهد و Server فقط ciphertext محدودشده را می‌بیند.
- گالری سبک داخل چت اضافه شد که تصاویر و ویس‌های موجود در همان چت را بدون ساخت کپی یا ایندکس جدا نمایش می‌دهد. تصویر خصوصی فقط نزدیک Viewport دریافت و در مرورگر رمزگشایی می‌شود؛ ویس خصوصی در Gallery فقط با لمس کاربر دانلود و باز می‌شود.
- Quality انتخابی Host/Admin بلافاصله در state فعال می‌شود؛ HLS روی Level واقعی انتخاب‌شده قفل می‌شود و Sourceهای چندکیفی URL همان Resolution را دریافت می‌کنند. برای Sourceهایی که قبلاً Resolve شده‌اند، تغییر کیفیت از Sourceهای Cache‌شده همان Room استفاده می‌کند و دوباره منتظر API Provider نمی‌ماند.
- قفل اتاق، Private Mode را فعال می‌کند: متن، تصویر و ویس قبل از خروج از مرورگر با AES-256-GCM رمز می‌شوند. کلید محتوا در URL fragment/مرورگر است و برای Server ارسال نمی‌شود. فعال‌کردن Private Mode از حالت عمومی کلید تازه می‌سازد و خاموش‌کردنش کلید ذخیره‌شده Room را پاک می‌کند؛ محتوای قبلی Chat هم در تغییر حالت پاک می‌شود تا plaintext و ciphertext با هم مخلوط نشوند.
- میزبان از پنل حریم خصوصی می‌تواند لینک خصوصی اعضا را کپی کند؛ عضو بدون کلید، محتوای رمز‌شده را نمی‌بیند.
- تصویر و ویس هر دو با Chunkهای محدود منتقل می‌شوند تا payload بزرگ Socket.IO/HTTP polling پشت Nginx/CDN ساخته نشود. Upload Sessionها TTL و سقف RAM رزروشده دارند و با خروج کاربر Abort می‌شوند.
- محدودیت‌های Upload، TTL یک‌ساعته Chat Media، Rate Limit و Lazy media loading حفظ شده‌اند تا Gallery/E2EE باعث رشد بی‌حد RAM/Disk نشوند.

> نکته امنیتی: E2EE جلوی خواندن محتوای ذخیره‌شده/عبوری توسط Server را می‌گیرد، اما یک Server/Hosting کاملاً مخرب که بتواند JavaScript ارسالی به مرورگر را تغییر دهد می‌تواند برای سرقت کلید تلاش کند. برای مدل تهدید قوی‌تر باید Client قابل‌تأیید/امضاشده یا اپ مستقل داشته باشی.

## v3.20.0

- ارسال عکس دوربین و گالری به آپلود تکه‌ای تبدیل شد تا محدودیت body در Nginx/CDN باعث گیرکردن ارسال نشود.
- همه مراحل ارسال عکس timeout و پیام خطای مشخص دارند؛ spinner دیگر بی‌نهایت نمی‌ماند.
- تغییر کیفیت Host/Admin با event اختصاصی `room:quality` همان لحظه روی کل اتاق اعمال می‌شود.
- خروج از صفحه با beacon امضاشده به سرور اعلام می‌شود تا Room خالی سریع پاک شود.
- منطق Quality، Chat Media و Socket acknowledgement به فایل‌های جدا در `lib/` و `server/` منتقل شد.
- ساختار جدید پروژه در `ARCHITECTURE.md` مستند شده است.

- سقف تصویر چت از 5MB به 3MB کاهش یافت و هم Client و هم Server آن را enforce می‌کنند.
- Play/Pause feedback کوتاه و مرکزی روی خود ویدیو اضافه شد.
- آیکن Fullscreen در حالت Fullscreen به Exit Fullscreen تبدیل می‌شود و میانبر فیزیکی F یا کلید فارسی `ب` هر دو کار می‌کنند.
- Quality Picker به Resolutionهای واقعی گزارش‌شده توسط منبع/HLS تغییر کرد و انتخاب کیفیت روی Level/Source واقعی اعمال می‌شود.
